# FocusFix Web (`focusfix-web`)

الموقع العام لمنصة **FocusFix** لخدمات صيانة أجهزة Apple المنزلية في القاهرة والجيزة.

- **الرابط والدومين:** [https://focusfix.net/](https://focusfix.net/)
- **رقم التواصل والواتساب:** `+201009911934`
- **التقنيات المستخدمة:**
  - Next.js 15 (App Router)
  - TypeScript (Strict Mode)
  - Tailwind CSS v4
  - Radix UI / shadcn/ui
  - React Hook Form + Zod
  - TanStack Query
  - Lucide React & Framer Motion

## أوامر التشغيل

```bash
pnpm install # أو npm install
pnpm dev     # تشغيل السيرفر المحلي على http://localhost:3000
pnpm build   # بناء المشروع للإنتاج
pnpm start   # تشغيل سيرفر الإنتاج
```
